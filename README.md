# NGO Volunteer Matching System

A full-stack web application that connects NGOs with volunteers based on their skills and interests. The platform provides a simple way for volunteers to discover opportunities, register with NGOs, and support social initiatives.

## 🚀 Features

- 👤 User Signup and Login
- 🤝 Volunteer Registration
- 🏢 NGO Listing
- 🔍 Volunteer–NGO Matching
- 💰 Donation Management
- 📧 Email Notifications
- 🗄️ Database Integration
- 🌐 Full-stack Web Application

## 🛠️ Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MySQL

### Other Technologies
- Nodemailer
- REST API
- CORS
- dotenv

## How to Run

1. Clone the repository from GitHub.

2. Open the project folder in VS Code.

3. Open the terminal in the project folder.

4. Install the required dependencies:
   npm install

5. Configure the required environment variables in the `.env` file.

6. Start the backend server:
   node backend/server.js

7. Open the application in your browser:
   http://localhost:3000

8. The NGO Volunteer Matching System will now be running locally.
